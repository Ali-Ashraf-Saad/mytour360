# جولة 360° — دار فيو (DarView)

## التشغيل المحلي
    python server.py          ← ثم افتح http://localhost:8000/?edit
(بدون PHP. كلمة السر الافتراضية: change-me، ولتغييرها:  EDIT_PASSWORD=سري python server.py)

أو بوجود PHP:  php -S localhost:8000  — ثم افتح /?edit

## الرفع على استضافة (PHP مثل InfinityFree)
1. افتح api/save.php وغيّر EDIT_PASSWORD إلى كلمة سر قوية (يُرفض الحفظ بالكلمة الافتراضية خارج الجهاز المحلي).
2. ارفع المجلد كاملًا وتأكد أن مجلد data قابل للكتابة.
3. افتح  https://موقعك/?edit  للتحرير. الزوار العاديون لا يرون زر المحرر.

## أين تُحفظ التعديلات؟
زر "💾 حفظ في الموقع" يرسل الإعدادات إلى api/save.php الذي يكتبها في data/tour.json، فيراها كل زائر فورًا.
إن لم يوجد data/tour.json يستخدم الموقع js/config.js كقيم افتراضية.

## الهيكل
    index.html · css/style.css · js/app.js · js/config.js (افتراضي)
    api/save.php (الحفظ على الاستضافة) · server.py (خادم محلي للتجربة)
    data/tour.json (التعديلات المحفوظة) · images/ · js/three.min.js

## وضع المحرر
اسحب السهم لتحريكه (أو اخترْه وانقر مرتين على المكان الجديد)، عدّل النص والهدف واسم المشهد من اللوحة، ثم احفظ.
## رفع مشهد جديد (الطريقة الأسهل)
من المحرر: "📤 رفع صورة 360° كمشهد جديد" ← اختر الصورة من جهازك. تُضغط تلقائيًا (حد أقصى 6144px) وتُرفع إلى images/ وتُحفظ كمشهد، مع أسهم تلقائية.
على الاستضافة: غيّر كلمة السر في api/config.php (تُستخدم لكل من الحفظ والرفع).

## إضافة مشهد جديد (يدويًا)
1. ضع الصورة في images/ (وارفعها إلى الاستضافة).
2. من المحرر اضغط "🖼 إضافة مشهد جديد" واكتب اسم الملف (مثل 3.jpg) ثم احفظ.
   (تُضاف أيضًا أسهم تلقائية بين المشهد الحالي والجديد لتعدّلها.)
   أو أضفه في js/config.js — تُدمج المشاهد الجديدة فيه تلقائيًا مع المحفوظ في data/tour.json.

## الخروج من المحرر
زر "✕ خروج" أعلى اللوحة، أو مفتاح Esc، أو الزر أعلى الصفحة.
